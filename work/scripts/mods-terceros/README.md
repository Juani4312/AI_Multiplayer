# Copia de los scripts de `<juego>/mods/` (papito)

La carpeta `mods/` de la instalación de Alien: Isolation tiene mods de terceros con scripts para activarlos y
desactivarlos (ver `instructions.md`). Esta es una copia versionada de **los scripts y notas** (no de los mods): si se
cambian allá, copiarlos acá. `work/scripts/mode.sh` usa `<juego>/mods/mods-desarrollo.sh` (test: apaga los mods que
interfieren con el coop; play: los vuelve a prender).
